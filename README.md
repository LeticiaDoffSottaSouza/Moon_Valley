# Moon Valley — versão 27

HTML, CSS e JavaScript, com todas as imagens do jogo.

## Como abrir

Extraia o ZIP inteiro. Abra index.html em um navegador moderno, mantendo a pasta assets junto dos arquivos. Para editar e testar, também pode abrir a pasta no VS Code e usar a extensão Live Server.

## Controles

WASD ou setas: andar. E: interagir. Espaço: pular. N: nadar perto de uma margem. I: mochila. M: mapa. J: missões. 1 a 8: ferramentas. No celular, use o joystick e os botões na tela.

## Esta versão

Inclui as correções mais recentes: luminárias coloridas e opção branca, brilho ao anoitecer dentro e fora da casa e pesca na ponte de cima, além dos demais sistemas do jogo.

## Seu progresso

O progresso fica salvo no navegador. Para levar sua partida do site para esta cópia, exporte o salvamento pelo menu do jogo e depois importe o arquivo na cópia local. A partida do site não é incluída neste ZIP.
