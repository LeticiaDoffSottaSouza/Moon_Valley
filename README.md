# 🌙 Moon Valley

> Um mundo encantador de aventuras, descobertas e pequenas maravilhas.

**Moon Valley** é um jogo desenvolvido com HTML, CSS e JavaScript, que combina exploração, interação com o ambiente e atividades em um universo acolhedor. O projeto reúne cenários interativos, ferramentas, mecânicas de jogo e uma atmosfera especial para descobrir e explorar.

---

## ✨ Sobre o jogo

Moon Valley é uma experiência de aventura e exploração que permite ao jogador interagir com diferentes elementos do cenário, realizar atividades e descobrir os detalhes do mundo ao seu redor.

O jogo foi desenvolvido utilizando tecnologias web e pode ser executado diretamente no navegador, sem a necessidade de instalar um aplicativo adicional.

## 🌷 Funcionalidades

- Exploração de cenários e ambientes interativos.
- Movimentação e interação com elementos do mundo.
- Sistema de ferramentas e atividades.
- Mochila para acessar os itens do jogador.
- Mapa para auxiliar na exploração.
- Sistema de missões.
- Efeitos de iluminação e ambientação, incluindo mudanças ao anoitecer.
- Luminárias coloridas e opção de iluminação branca.
- Atividade de pesca, incluindo a ponte superior.
- Controles adaptados para dispositivos móveis.
- Sistema de salvamento e transferência de progresso.

## 🕹️ Controles

| Tecla | Função |
|:---:|---|
| `W`, `A`, `S`, `D` ou setas | Movimentar o personagem |
| `E` | Interagir |
| `Espaço` | Pular |
| `N` | Nadar próximo à margem |
| `I` | Abrir a mochila |
| `M` | Abrir o mapa |
| `J` | Consultar missões |
| `1` a `8` | Selecionar ferramentas |

### 📱 Dispositivos móveis

Em celulares e outros dispositivos com tela sensível ao toque, utilize o joystick virtual e os botões de ação exibidos na tela para movimentar o personagem e interagir com o ambiente.

## 💾 Salvamento e progresso

O progresso da partida fica armazenado no navegador utilizado para jogar.

Para transferir uma partida da versão online para uma cópia local:

1. Acesse o jogo pelo site e exporte o salvamento pelo menu.
2. Extraia os arquivos do projeto para o computador.
3. Abra o jogo localmente e importe o arquivo de salvamento.

**Importante:** os dados de uma partida iniciada no site não estão incluídos no arquivo ZIP. Para continuar uma partida existente, é necessário exportar e importar o salvamento manualmente.

## 🚀 Como executar o projeto

### Requisitos

- Um navegador moderno, como Google Chrome, Microsoft Edge ou Mozilla Firefox.
- Os arquivos completos do projeto, incluindo a pasta `assets`.

### Executando localmente

1. Baixe o arquivo ZIP do projeto.
2. Extraia todos os arquivos para uma pasta no computador.
3. Mantenha a pasta `assets` junto dos demais arquivos, preservando sua estrutura original.
4. Abra o arquivo `index.html` em um navegador moderno.

### Executando pelo Visual Studio Code

Para editar e testar o projeto:

1. Abra a pasta do projeto no Visual Studio Code.
2. Instale a extensão **Live Server**, caso ainda não esteja instalada.
3. Clique com o botão direito no arquivo `index.html`.
4. Selecione **Open with Live Server**.

O jogo será aberto no navegador, permitindo testar as alterações realizadas no código.
